# Calculator

## Documentation
### Operations
  #### Binary operations
    +, -, *, / = addition, subtraction, multiplication and division
    ^, /^ = exponentiation and n-th root
    % = modulo
    log = the log
  #### Unary operations
    sin, cos, tan = sine, cosine and tangent of *x*
    asin, acos, atan = inverse sine, cosine and tangent of *x*
    csc, sec, cot = cosecant, secant and cotangent of *x*
    acsc, asec, acot = inverse cosecant, secant and cotangent of *x*
    ! = factorial of *x*
    ln = natural logarithm of *x*
    sqrt = square root of *x*
### Constants
  #### Common constants
    pi = π, 3.14159265
    tau = τ, double of π, 6.28318531
    e = Euler's number, 2.71828182
### Statistics 
  #### Basic Statistics
    mean x y z = takes the mean of the array
    median x y z = takes the median of the array
    mode x y z = takes the mode of the array
    range x y z = takes the range of the array
